## 📖 Sobre o Projeto

O **FEED SEGURO: Simulador de Riscos Digitais** é uma aplicação web educativa desenvolvida no âmbito da disciplina **Tópicos Especiais III** do curso de **Licenciatura em Computação** do **Instituto Federal de Mato Grosso do Sul (IFMS) – Câmpus Jardim**.

O projeto aborda um problema crítico enfrentado por crianças e adolescentes na contemporaneidade: a **dificuldade em identificar golpes digitais, perfis falsos, tentativas de aliciamento, cyberbullying e superexposição de dados pessoais nas redes sociais**.

Alinhada aos princípios e direitos do **ECA Digital** (proteção integral, privacidade, segurança e educação digital), a ferramenta simula o feed de uma rede social no celular, desafiando o estudante a avaliar situações reais do cotidiano digital e gerando, ao final, um **Diagnóstico Educativo Personalizado**.

---

## 🚀 Principais Funcionalidades

### 📱 Feed Interativo Mobile-First
* **Simulação Realista de Rede Social**: Apresenta postagens patrocinadas, stories públicos, comunicados escolares e mensagens diretas (DM) com avatares, arrobas, links e contadores de engajamento.
* **Barra de Progresso Dinâmica**: Acompanhamento visual em tempo real do avanço do estudante pelas situações-problema.

### ⚖️ Sistema de Decisão (`✅ Seguro` vs `⚠️ Perigo`)
* **Classificação Prática**: Em cada publicação do feed, o usuário deve analisar os sinais de alerta e decidir se a interação representa um ambiente **Seguro** ou um **Perigo**.
* **Feedback Educativo Imediato**: Assim que o botão é acionado, o simulador informa se o aluno acertou ou errou, explicando a armadilha (ex.: *phishing*, *grooming*, vazamento de localização) e qual direito do **ECA Digital** está envolvido.

### 📊 Algoritmo de Contabilização e Diagnóstico Educativo Final
* **Cálculo Automatizado de Desempenho**: Contabiliza o total de acertos, erros e o percentual de aproveitamento global.
* **Classificação por Perfil de Segurança**:
  * 🏆 **Guardião(ã) Digital ($\ge 80\%$):** Domínio elevado na identificação de riscos e proteção de dados.
  * ⚠️ **Navegador(a) em Alerta ($50\%$ a $79\%$):** Reconhece ameaças comuns, mas requer atenção a golpes de engenharia social.
  * 🚨 **Alta Vulnerabilidade Digital ($< 50\%$):** Alerta vermelho com orientações prioritárias de autoproteção.
* **Relatório Item a Item**: Lista revisional detalhando cada postagem analisada e a diretriz correspondente do **ECA Digital**.

### 🔄 Dupla Implementação (Web HTML/JS & Python/Streamlit)
* O projeto conta com duas implementações completas da mesma lógica para validação comparativa e flexibilidade de uso em sala de aula.

## 💻 Como Rodar o Projeto Localmente

### 1. Clone o repositório
```bash
git clone https://github.com/skyzinha-chan/feed-seguro-eca-digital.git
cd feed-seguro-eca-digital
```

### 2. Executando a Versão Web (HTML/CSS/JS)
Não requer instalação de pacotes. Basta abrir o arquivo `versao_web/index.html` diretamente no navegador ou executar:
```bash
start versao_web/index.html
```

### 3. Executando a Versão Python (Streamlit)
1. **Instale a dependência:**
   ```bash
   python -m pip install -r versao_streamlit/requirements.txt
   ```
2. **Inicie o servidor local:**
   ```bash
   python -m streamlit run versao_streamlit/app.py
   ```
   Acesse no navegador em `http://localhost:8501`.

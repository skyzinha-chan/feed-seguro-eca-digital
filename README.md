## 📂 Estrutura do Repositório

* 📁 **[`versao_web/`](./versao_web/)**: Versão em HTML, CSS e JavaScript puro com visual de smartphone e rede social.
  * `index.html` — Estrutura das telas (Boas-vindas, Feed Interativo e Diagnóstico Final).
  * `style.css` — Estilização mobile-first.
  * `script.js` — Base de dados dos posts, lógica dos botões `✅ Seguro` / `⚠️ Perigo` e algoritmo de diagnóstico educativo.
* 📁 **[`versao_streamlit/`](./versao_streamlit/)**: Versão 100% em Python utilizando Streamlit.
  * `app.py` — Aplicação completa em Streamlit.
  * `requirements.txt` — Dependências para deploy no Streamlit Cloud.
* 📄 **[`RASCUNHO_PARTE_TALITA.md`](./RASCUNHO_PARTE_TALITA.md)**: Documentação técnica e fluxograma lógico do algoritmo para o Relatório Final.
